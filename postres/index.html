Tarta de Queso

Ingredientes:

  • 200g de galletas
  • 100g de mantequilla
  • 500g de queso crema
  • 200g de azúcar
  • 3 huevos
  • 200ml de nata para montar

Instrucciones:

  1. Tritura las galletas y mézclalas con la mantequilla derretida.
  2. Presiona la mezcla en el fondo de un molde para tartas.
  3. Bate el queso crema con el azúcar hasta obtener una mezcla suave.
  4. Añade los huevos uno a uno, mezclando bien después de cada adición.
  5. Incorpora la nata y mezcla hasta que esté todo bien integrado.
  6. Vierte la mezcla sobre la base de galletas y hornea a 160°C durante 50 minutos.
  7. Deja enfriar y refrigera antes de servir.
Receta por: Ana García

Comentario:

¡Esta tarta de queso es deliciosa y muy fácil de hacer! A mis amigos les encantó cuando la preparé para una reunión.
